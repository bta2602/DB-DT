# Демонстрация StudyHUB

## Подготовка

```bash
npm ci
npm run demo:setup
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). В шапке кабинета можно
менять роль без выхода и ввода пароля. Все аккаунты и данные в деморежиме вымышлены.

## Сценарий показа

1. **Студент.** Откройте «Сегодня», расписание, предметы и задания.
   В карточке предмета покажите оценки, посещаемость и скачивание материала.
2. **Преподаватель.** В «Мои задания» создайте задание для группы ИС-21
   и предмета «Базы данных». Укажите понятный заголовок и будущий срок.
   Здесь же можно загрузить учебный материал.
3. **Студент.** В «Задания» найдите созданную работу. Откройте её и отправьте
   небольшой TXT- или SQL-файл. Статус изменится на «На проверке».
4. **Преподаватель.** Откройте «Проверка работ», выберите отправленную работу,
   посмотрите файл, поставьте оценку и напишите комментарий. Сохраните проверку.
5. **Студент.** Откройте задание ещё раз: появятся оценка, комментарий
   и статус «Проверено».
6. **Преподаватель.** В журнале выберите группу и предмет, измените оценку.
   На вкладке посещаемости отметьте студентов и сохраните изменения.
7. **Администратор.** Покажите создание и редактирование группы, предмета,
   пользователя и аудитории. Добавьте занятие в расписание. Попытка поставить
   другую пару в то же время для той же группы должна показать конфликт.
8. В обзоре администратора опубликуйте объявление. Переключитесь на студента:
   объявление появится в его кабинете.
9. Обновите страницу и перезапустите сервер: внесённые изменения сохранятся.

Профиль позволяет изменить имя. Кнопка обновления в шапке перечитывает данные,
а кнопка выхода возвращает на страницу входа. На телефоне меню открывается
кнопкой слева сверху и закрывается после выбора раздела.

## Что лежит в демонстрационной базе

Первый набор: 16 пользователей (включая администратора), 2 группы,
4 предмета, 4 аудитории, 18 занятий, 6 заданий, 11 сданных работ,
оценки, посещаемость, материалы и объявления.

`npm run demo:seed -- --more` добавляет расширенный набор.
Повторный запуск не создаёт копии записей и не сбрасывает оценки или пароли.

Даты привязаны к первому заполнению. Для новой демонстрации с другими датами
задайте новый пустой каталог в `STUDYHUB_DATA_DIR` и выполните
`npm run demo:seed`. Старую базу удалять не нужно.

## Как коротко объяснить учителю

«У нас Next.js отвечает за страницы и серверный API. React-компоненты показывают
интерфейс и отправляют запросы при нажатии кнопок. Сервер проверяет сессию
и права пользователя, затем читает или изменяет отдельную SQLite-базу.
Демонстрационные роли — это три подготовленных аккаунта. Изменения сохраняются
в базе, поэтому остаются после перезапуска сайта. В GitHub находятся исходники,
схема базы и скрипт заполнения, а сама база и пароли туда не попадают».

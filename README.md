# StudyHUB

**Учебная информация в одном месте**

StudyHUB — веб-платформа для студентов и преподавателей колледжей и университетов, которая объединяет электронный журнал и личный учебный кабинет.

В этом README описаны концепция проекта и возможности первой версии.

## Реализация и запуск

Проект использует Next.js App Router, React и TypeScript. Главная страница открывается
на `http://localhost:3000/`; интерфейс отрисовывается компонентами React.

- `app/*/page.tsx` — страницы и маршруты (`/schedule`, `/journal`, `/tasks` и другие).
- `app/layout.tsx` — серверная загрузка сессии и доступных пользователю данных.
- `components/studyhub/` — интерфейс кабинетов, формы и общий клиентский контекст.
- `app/styles/` — стили интерфейса.
- `app/api/` — серверные обработчики HTTP-запросов.
- `lib/studyhub/` — права доступа, база SQLite, типы данных и общие функции.
- `.studyhub/` — приватная локальная база и файлы доступа, исключённые из Git и сборки.

Нужен Node.js 24 или новее. Установить зависимости: `npm install`.
Запуск разработки: `npm run dev`. Проверка сборки: `npm run build`.
Запуск собранного сайта: `npm start`.

Учебные данные остаются в существующей базе. Старый адрес `/studyhub/index.html`
перенаправляется на главную страницу Next.js для совместимости с закладками.

## Назначение проекта

StudyHUB помогает студентам организовать учебную деятельность: просматривать расписание, следить за оценками и посещаемостью, получать задания и отправлять выполненные работы.

Преподаватели смогут публиковать учебные материалы, проверять работы и вести журнал. Основная цель проекта — собрать необходимую учебную информацию в одном понятном и удобном интерфейсе.

## Разделы сайта

### 1. Сегодня

Главная страница с актуальной информацией:

- ближайшие занятия;
- важные объявления;
- задания, срок сдачи которых приближается.

### 2. Расписание

Расписание занятий на неделю с указанием:

- предмета;
- даты и времени занятия;
- аудитории;
- преподавателя.

### 3. Предметы

Список изучаемых дисциплин. Внутри каждого предмета студент сможет просматривать:

- свои оценки;
- сведения о посещаемости;
- учебные материалы.

### 4. Задания

Раздел для получения и сдачи учебных работ. Для каждого задания предусмотрены:

- описание и условия выполнения;
- прикреплённые материалы;
- срок сдачи;
- отправка файла с выполненной работой;
- оценка и комментарий преподавателя;
- статус: «Нужно выполнить», «Сдано» или «Проверено».

### Дополнительные страницы

- **Вход в систему** — авторизация пользователя.
- **Профиль** — имя, роль, учебная группа студента и настройки аккаунта.
- **О проекте** — общая информация о StudyHUB, доступная гостям.

## Роли пользователей

| Роль | Возможности |
| --- | --- |
| **Администратор** | Создаёт и редактирует аккаунты, назначает роли, управляет учебными группами и предметами, закрепляет преподавателей за дисциплинами и обновляет расписание. |
| **Преподаватель** | Работает со своими предметами и группами: публикует материалы и задания, просматривает отправленные работы, выставляет оценки, оставляет комментарии и отмечает посещаемость. |
| **Студент** | Просматривает расписание своей группы, собственные оценки и посещаемость, получает задания, отправляет выполненные работы и читает комментарии преподавателя. |
| **Гость** | Знакомится с общей информацией о платформе и может перейти на страницу входа. |

Учебные данные доступны после авторизации в соответствии с ролью пользователя. Студент видит собственные оценки и работы, а преподаватель — информацию по закреплённым за ним предметам и группам.

## Пример использования

1. Преподаватель публикует лабораторную работу, прикрепляет материалы и устанавливает срок сдачи.
2. Студент видит работу в разделе «Задания» и изучает её условия.
3. Студент прикрепляет выполненную работу. Её статус меняется на «Сдано».
4. Преподаватель проверяет работу, выставляет оценку и оставляет комментарий.
5. Студент видит результат проверки и статус «Проверено» в своём кабинете.

## Интерфейс

Интерфейс планируется минималистичным:

- светлый фон и один основной акцентный цвет;
- понятное меню из четырёх основных разделов;
- приоритет ближайших занятий и сроков сдачи на главной странице;
- адаптация для компьютеров и смартфонов;
- понятные обозначения статусов заданий.

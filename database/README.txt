StudyHUB — схема базы данных (bekulanbalkashbay-dot)

Файл: database/migrations/001_initial.sql
Целевая СУБД: PostgreSQL 16+. Это предлагаемая первая миграция для новой БД.
В исходниках нет тестовых людей, паролей, занятий и оценок. Миграция не применялась.

Перед применением согласовать схему с bta2602 и выбранным серверным стеком.
Существующую рабочую БД сначала резервировать и проверять отдельно.
При наличии уже созданных таблиц требуется отдельная миграция, а не слепой запуск.

API DTO использует camelCase; SQL — snake_case. Backend делает явное отображение.
UUID передаются строками; timestamptz — ISO с часовым поясом; версии — числами.
Для снятой оценки хранить grade NULL и сохранять версию, а не удалять её историю.
Отсутствие посещаемости означает «не отмечен», а не «отсутствует».
Одна сдача относится к одному заданию и одному студенту.

Индексы и ограничения пересечений используют btree_gist; право создания extension
должно быть доступно на выбранном сервере. Применение и откат проверить в отдельной БД.
Секреты подключения и дампы с персональными данными в Git не добавлять.

# StudyHUB

**Учебная информация в одном месте:** расписание, задания, оценки и посещаемость.

Учебный проект на **Next.js 16, React 19 и TypeScript**. Все страницы и серверные
API работают через Next.js App Router. Данные хранятся в отдельной SQLite-базе
на компьютере, а не в массиве внутри браузера.

## Быстрый запуск для демонстрации

Нужен **Node.js 24+**. В терминале из папки проекта:

```bash
npm ci
npm run demo:setup
npm run dev
```

Откройте [localhost:3000](http://localhost:3000). На странице входа выберите
**«Студент»**, **«Преподаватель»** или **«Администратор»**. Эти же кнопки доступны
в верхней панели кабинета. Пароль для демонстрационного переключения не нужен.

`demo:setup` создаёт `.env.local` и базу в соседней с проектом папке
`../studyhub-data/demo/`. Это отдельный каталог: база, файлы работ, пароли
и резервные копии не отправляются в GitHub. Повторный запуск не удаляет
внесённые изменения. Даты примеров выбираются относительно первого заполнения.

Для показа без разработки: `npm run build`, затем `npm start`.
Остановить сервер можно сочетанием **Ctrl+C** в его терминале.

## Что умеет сайт

| Роль          | Возможности                                                                                                                      |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Студент       | Видит расписание своей группы, свои оценки и посещаемость; скачивает материалы, отправляет работы и читает результат проверки.   |
| Преподаватель | Создаёт задания и материалы для своих дисциплин, проверяет работы, ставит оценки и отмечает посещаемость своих групп.            |
| Администратор | Создаёт и редактирует пользователей, группы, предметы, аудитории и расписание; закрепляет преподавателей и публикует объявления. |
| Гость         | Читает страницу «О проекте», регистрируется или входит в аккаунт.                                                                |

Регистрация создаёт студента без группы. Администратор назначает группу
и при необходимости меняет роль. Обычный вход по почте и паролю сохранён.

Файлы работ и материалов: PDF, DOCX, ZIP, SQL, TXT, PNG, JPG и JPEG до 20 МБ.
Сервер проверяет формат, размер и право доступа. Оценки, работы и расписание
не исчезают после обновления страницы или перезапуска сервера.

## Структура проекта

```text
app/                    Страницы Next.js, layout, состояния загрузки и ошибок
  api/                  HTTP API: вход, данные, справочники, задания, файлы
  styles/               Общие стили и стили кабинетов
components/studyhub/    React-компоненты, формы, меню и переключатель ролей
lib/studyhub/           Серверная логика, права доступа, типы и общие функции
database/
  schema.mjs            Рабочая схема SQLite: таблицы, связи и индексы
  seeds/                Примеры только для команды заполнения базы
  design/               Первоначальный проект PostgreSQL команды
scripts/                Подготовка демонстрации и создание администратора
tests/                  Автоматическая проверка API и сохранения данных
docs/                   Архитектура, описание API, сценарий демонстрации
```

При настройке по этой инструкции данные лежат **за пределами этого дерева**. Их адрес задаётся
`STUDYHUB_DATA_DIR` в локальном файле настроек.

## Обычный режим

Для базы настоящих пользователей скопируйте `.env.example` в `.env.local`,
укажите **другой каталог данных** и оставьте `STUDYHUB_DEMO_MODE=false`.
Создайте первого администратора командой из таблицы. Она выведет путь
к приватному файлу со случайным паролем.

Кнопки ролей доступны только в демонстрационном режиме. Сервер не разрешит
включить их на базе с обычными аккаунтами. В демонстрационную базу следует
вводить только вымышленные данные, поскольку в ней есть свободный вход администратора.

GitHub хранит исходники. Для этого приложения нужен работающий Node.js-сервер:
обычный GitHub Pages не запускает Next.js API и SQLite. Публикация в облаке
для текущей версии не настраивалась. Подтверждение почты и восстановление
пароля пока не реализованы.
